The URL of the file you are reading was sent to the reporter. Deleting the file
would turn that link into a 404 for the one person most likely to follow it, so the
path stays and forwards instead.

- **The branch link is dead.** `security/findings-2026-08` was merged into `main` and
  the branch deleted.

  every id in the commit table. The wiki version has been re-pointed at the ids that
  exist on `main`.
